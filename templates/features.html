// CORE SECURITY

Security Features

🔐
AES-256-CFB Encryption

Every message is encrypted using AES-256 in CFB mode before it leaves your device. The same standard trusted by governments and militaries worldwide.

256-bit key length — 2²⁵⁶ possible keys
CFB mode with random IV per message
Unique session key for every conversation
Impossible to brute force with current technology
🔑
RSA-2048-OAEP Key Exchange

Public/private key pairs generated for every user. The AES session key is encrypted with the receiver's RSA public key — only their private key can decrypt it.

2048-bit RSA key pairs auto-generated
OAEP padding for enhanced security
SHA-256 hash function within OAEP
Private key never transmitted over network
🛡️
bcrypt Password Security

Passwords are never stored in plaintext. bcrypt adaptive hashing with unique salts ensures passwords are resistant to rainbow table and brute force attacks.

bcrypt adaptive hashing algorithm
Unique random salt per password
Resistant to rainbow table attacks
Cost factor makes brute force impractical
🌐
Zero Knowledge Architecture

The server stores only encrypted ciphertext. Even with full server access, messages cannot be read. True end-to-end encryption by mathematical design.

Server stores only ciphertext
No plaintext ever touches the server
Decryption happens client-side only
Mathematical privacy guarantee
