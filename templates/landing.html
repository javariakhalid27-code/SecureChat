How Encryption Works

01
Register
RSA-2048 key pair auto-generated. Public key shared. Private key stays secret.
02
Encrypt
AES-256 session key encrypts your message. RSA wraps the session key.
03
Transmit
Only ciphertext travels through the server. Zero plaintext. Zero knowledge.
04
Decrypt
Receiver's private key unwraps AES key. Message decrypted locally. Only receiver can read.
